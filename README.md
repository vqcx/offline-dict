# 离线英汉词典 · Offline English-Chinese Dictionary

一个**纯静态、完全离线**的英汉词典网页。没有后端、不用安装、不联网也能查词背词。

双击 `index.html` 就能用，手机上用浏览器打开也一样。

## 功能

- **查词**：输入英文查中文，或输入中文反查英文
- **完整词条**：音标、词性、中文释义、英英释义、词形变化、搭配、例句
- **背单词**：英→中 / 中→英 双向选择题，答对绿色、答错红色
- **四个背词范围**：核心词 / 全部词 / 收藏词 / 只练错题
- **收藏**：查词时一键收藏，可以只背自己收藏的词
- **错题本**：答错自动记录，答对自动移除，可以单独练错题
- **离线编辑**：音标、释义、例句等七个字段都能改，也能新建自己的词

## 快速开始

### 1. 准备词库

本项目**不包含词库数据**（体积大，且有独立的开源协议），需要自己生成一次。

从 [ECDICT](https://github.com/skywind3000/ECDICT) 下载数据库：

- 推荐：[Releases 页面](https://github.com/skywind3000/ECDICT/releases) 下载 `ecdict-sqlite-28.zip`
- 或 clone 仓库后自行转换

解压得到 `stardict.db`，然后运行：

```bash
python3 tools/build_data.py /path/to/stardict.db
```

会在 `data/` 下生成 `dict.js`（约 21,000 词，5 MB 左右）。

### 2. 打开

直接用浏览器打开 `index.html` 即可，不需要启动服务器。

> **为什么用 `.js` 而不是 `.json` 存词库？**
> 浏览器用 `file://` 协议打开本地页面时，`fetch()` 读取本地 JSON 会被 CORS 策略拦截，但 `<script src>` 加载 JS 不受限制。所以词库以 `window.DICT_DATA = [...]` 的形式存成 `.js` 文件。

### 3. 手机上使用

把整个目录复制到手机存储，用浏览器打开 `index.html` 即可。

如果需要单文件版（所有代码和词库打包成一个 HTML），可以自行内联，或者用任意打包工具；单文件版便于分享。

## 词库说明

词库来自 [ECDICT](https://github.com/skywind3000/ECDICT)，MIT 协议，由 [skywind3000](https://github.com/skywind3000) 维护。

`tools/build_data.py` 的筛选口径是**日常常用词 + 文学古旧词**：

- `frq`（当代语料词频）≤ 20000 —— 覆盖现代日常用语
- `bnc`（英国国家语料库词频）≤ 15000 —— 覆盖 19 世纪及以前的文学作品用语
- 或命中考试大纲标签、柯林斯星级、牛津核心词表

同时排除了：专有名词（首字母大写）、变形词（如 hens）、无音标词条。

如果你想换一个范围（比如只要四六级词，或者要全部词），改 `tools/build_data.py` 顶部的 `MAX_FRQ` / `MAX_BNC` 阈值即可。

## 文件结构

```
index.html          页面结构
css/app.css         样式（含深色模式）
js/app.js           主逻辑：查词、反查、背词、收藏、错题、编辑
js/store.js         本地存储：自定义词条、收藏、错题
tools/build_data.py 从 ECDICT 生成 data/dict.js
data/dict.js        词库（自行生成，不入库）
```

## 隐私

所有数据都在你自己的浏览器里（localStorage），不上传任何服务器。项目本身不发起任何网络请求。

## 已知限制

- 数据存在浏览器 localStorage，**换浏览器或清缓存会丢失**
- 不同浏览器之间数据不互通
- 音标用的是 ECDICT 的音标编码，不是标准 IPA 符号，部分字符显示可能有差异
